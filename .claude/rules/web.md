# Web app (Next.js Pages Router)

- The web app is frontend only. Never add API routes (`src/pages/api`), `getServerSideProps` data access to the database, or server-side secrets.
- Every file under `apps/web/src/pages` becomes a route, so tests live in `apps/web/src/__tests__`.
- `AGENTS.md` in this app is generated by `next dev`; keep it committed.
- Next.js 16 differs from older versions. Read the version-matched docs in `node_modules/next/dist/docs/02-pages/` before using a Next API. `next lint` no longer exists; the root ESLint config covers the app.
- Styling uses Tailwind CSS 4 (configured in CSS, no `tailwind.config.js`) and daisyUI 5 (`@plugin "daisyui"` in `src/styles/globals.css`).
- Imports use bundler resolution: no `.ts`/`.tsx` extensions in import paths.
- Only `NEXT_PUBLIC_*` variables reach the browser; they must never hold secrets.
